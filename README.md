Customer Lifetime Value & Sales Metrics Analysis

This project demonstrates practical SQL skills by calculating customer lifetime value (LTV) and key sales metrics from sample order and product data. It showcases how to aggregate, analyze, and categorize customer behavior in a way that simulates real-world business analytics workflows.

Key Features

Revenue Calculations: Compute total revenue per order, product, and customer by multiplying quantity × unit_price.

Customer Metrics: Calculate purchase frequency and average order size.

Lifetime Value (LTV): Derived as purchase_frequency × avg_order_size to quantify customer value over time.

Tier Assignment: Assign customers to Platinum, Gold, Silver, or Bronze tiers based on LTV using CASE/WHEN logic.

Multi-Table Joins: Combine order, product, and customer tables for comprehensive analysis.

CTEs for Readability: Use Common Table Expressions to organize complex queries in a clean and maintainable structure.

Skills Demonstrated

SQL SELECT statements, JOINs, and aggregations (SUM, AVG, COUNT)

Conditional logic using CASE/WHEN

Data aggregation and grouping using GROUP BY

Use of CTEs to structure queries for clarity

Translating business logic into actionable insights

Purpose & Use Case

This project models a typical business analytics workflow, providing insight into customer behavior, sales trends, and revenue distribution. It is designed to be adaptable for Oracle SQL, MySQL, PostgreSQL, or other relational databases.

It can be extended to include:

Tier-level reporting and revenue summaries

Temporal analyses such as monthly or quarterly trends

Dashboards and visualizations for stakeholder reporting
